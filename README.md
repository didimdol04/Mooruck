## 🌱 About

**무럭무럭**은 식물의 물주기와 성장 기록을 한곳에서 관리할 수 있는 Android 애플리케이션입니다.

농사로 OpenAPI를 통해 식물을 검색하고, 식물별 광도·습도·온도·물주기 정보를 확인할 수 있습니다. 또한 물주기 기록과 성장 일지를 작성하고, 물주기 점수를 통해 자신의 식물 관리 습관을 확인할 수 있습니다.

---

## ✨ Features

- 🌿 농사로 OpenAPI를 활용한 식물 검색 및 정보 자동 입력
- 🪴 식물 등록, 조회, 수정 및 삭제
- 💧 물주기 기록 및 물주기 일정 관리
- ⭐ 물주기 기록 기반 물주기 점수 제공
- 📝 사진과 글을 활용한 성장 일지 작성
- 🔔 물주기 알림 및 Android 홈 화면 위젯 제공
- 💾 Room(SQLite) 기반 로컬 데이터 저장

## 🌱 무럭무럭

**무럭무럭**은 사용자가 키우는 식물의 물주기 일정과 성장 과정을 간편하게 관리할 수 있는 Android 식물 돌봄 앱입니다.

농사로 OpenAPI를 활용하여 식물 이름을 검색하고, 광도·습도·온도·물주기 정보를 불러올 수 있습니다. 등록한 식물은 메인 화면에서 한눈에 확인할 수 있으며, 물주기 기록과 성장 일지를 통해 식물의 변화를 꾸준히 기록할 수 있습니다.

앱의 데이터는 SQLite 기반의 로컬 데이터베이스에 저장되며, 별도의 로그인 없이 사용할 수 있습니다.

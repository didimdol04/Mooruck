## 🌱 무럭무럭

**무럭무럭**은 식물의 물주기와 성장 기록을 한곳에서 관리할 수 있는 Android 애플리케이션입니다.

사용자는 농사로 OpenAPI를 통해 식물을 검색하고, 식물별 광도·습도·온도·물주기 정보를 확인할 수 있습니다. 등록한 식물의 마지막 물주기 날짜를 기록하고, 사진과 글을 포함한 성장 일지를 작성하며 식물의 성장 과정을 관리할 수 있습니다.

### 주요 기능

- 농사로 API를 활용한 식물 검색 및 정보 자동 입력
- 식물 등록, 조회, 수정 및 삭제
- 물주기 날짜 기록 및 알림
- 사진과 글을 활용한 성장 일지 관리
- 등록 식물 개수와 물주기 점수를 제공하는 마이페이지
- SQLite 기반 로컬 데이터 저장
